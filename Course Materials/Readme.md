# Course Materials

This folder contains CEMBench ASM educational activities for teaching and learning activated sludge process concepts.

Each activity includes structured questions and instructions and may include additional CEMBench ASM files, supporting materials, and a video briefing.

Users who complete or review an activity are encouraged to submit the short feedback survey linked for each activity. Public activity ratings are based on user feedback.

## Activity Rating

The activity rating is based on the response to:

> **Overall, how would you rate this activity?**

Ratings use a five-point scale.

To avoid displaying unstable ratings based on very small numbers of responses, a public rating is shown only after at least **10 responses** have been collected.

After the minimum response count is reached, the average score is displayed together with the number of responses.

Example:

**★★★★☆ 4.4 / 5 — 37 responses**

## Contributing an Activity

Anyone who wishes to contribute a course material should prepare it in the same format as the activities in this repository, and submit the activity proposal to the developer team via etcsoftwareprojects@gmail.com. We will perform a final check of the activity in terms of format compliance and publish it through this repository as a new activity. Please note that your activity will be published with your name as a contributor.
